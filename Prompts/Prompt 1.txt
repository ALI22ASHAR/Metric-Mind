# Project: AI-Powered Automated BI Platform

I want to build a production-quality AI-powered Business Intelligence platform.

The core idea is:

A user uploads a CSV or Excel sales/business dataset. The system automatically profiles and understands the dataset, identifies useful business metrics/KPIs, calculates them deterministically, generates an interactive dashboard, and eventually provides an AI Data Analyst that can answer natural-language questions about the uploaded data.

The long-term architecture will contain:

* Python
* FastAPI
* PostgreSQL for application metadata
* DuckDB for analytical queries
* Polars/Pandas for data processing
* React + TypeScript for frontend
* LLM-based AI capabilities
* Structured AI outputs validated with Pydantic
* Agent/tool-based data analysis
* Automated insights
* Anomaly detection
* Natural-language data analysis

IMPORTANT ENGINEERING PRINCIPLE:

Separate deterministic analytics from AI reasoning.

The LLM must NOT be responsible for calculating business numbers.

For example:

Revenue = SUM(Quantity × Sale_Price)

Profit = Revenue - Cost

Profit Margin = Profit / Revenue × 100

These calculations must be performed by Python/SQL/DuckDB.

The AI should interpret the dataset, recommend metrics, create analytical plans, select tools, and explain validated results.
